## ⚠️ Note on Data Structure
The data files provided in this repository are the original raw output files. They may contain many columns generated during the simulation. Please disregard any columns not specifically mentioned below. Only the columns listed in the descriptions are relevant for reproducing the figures in the paper. Here, “*” in the filenames indicates different parameters for the corresponding figures.
